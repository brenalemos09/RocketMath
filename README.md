# 🚀 RocketMath

## Sobre o Projeto

O **RocketMath** é um jogo educacional desenvolvido com a engine **Godot**, criado como projeto acadêmico do curso de **Ciência da Computação da Universidade de Fortaleza (UNIFOR)**.

O objetivo do jogo é tornar o aprendizado da matemática mais divertido e interativo, utilizando elementos de gamificação para estimular o raciocínio lógico, a agilidade e o aprendizado por meio de desafios progressivos.

---

# Objetivo

Desenvolver um jogo educativo capaz de auxiliar crianças e estudantes no treinamento de operações matemáticas básicas através de uma experiência divertida e intuitiva.

---

# Funcionalidades

- Sistema de perguntas matemáticas;
- Mecânica de progressão por fases;
- Controle de personagem;
- Sistema de pontuação;
- Feedback de respostas corretas e incorretas;
- Interface intuitiva;
- Navegação entre telas;
- Menu inicial;
- Reinício de partidas.

# Mecânicas do Jogo

O jogador deve resolver corretamente os desafios matemáticos apresentados durante a partida para avançar nas fases e aumentar sua pontuação.

Durante o jogo são trabalhadas habilidades como:

- Raciocínio lógico;
- Cálculo mental;
- Atenção;
- Tempo de resposta;
- Resolução de problemas.
